# Retail Sales Performance Dashboard

## Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel to develop an interactive dashboard for business performance monitoring.

The dashboard will provide insights into sales trends, profitability, product performance, and regional performance. The goal is to transform raw transactional data into meaningful information that can support business decision-making.

## Business Objectives

The dashboard aims to answer the following business questions:

1. How do sales trends change over time?
2. Which product categories and sub-categories contribute most to sales and profitability?
3. Which products generate the highest sales and profit?
4. How does sales and profitability performance vary across regions?
5. Are there areas where high sales do not translate into strong profitability?
